# feat: v0.11.2 — hygiene cut

## Summary

Cross-model cutting-preparation analysis (session
`2026-05-20-002` — Researcher A Claude + Devil's Advocate Codex)
identified two **high-agreement** cuts safe for immediate execution:

1. The `models` config block (자기 자신을 "DEPRECATED in v0.7.7, slated for
   removal in v0.7.9" 로 표시해 둔 채 4 minor 늦게 v0.11.1까지 잔류).
2. Four CE-plugin-lifecycle vendored skills (`ce-update`, `ce-report-bug`,
   `ce-release-notes`, `ce-setup`) — compound-engineering 플러그인
   자체의 라이프사이클을 다루는 도구라 athanor (orchestrator) 정체성과
   무관. 모두 upstream에서 `disable-model-invocation: true`로 표시되어
   auto-trigger 안 됨.

Devil's Advocate (Codex) defended against larger cuts (vendor-prune,
sp-* narrow, doc-archive collapse) on T2-invariant / standalone-narrative
/ release-evidence grounds. v0.11.2는 그 defense에 걸리지 않는 **양쪽
voice 합의 영역만** 대상으로 한다. 큰 prune은 v0.12.0+ deferred.

## Decisions

- **D1.** v0.11.2는 양쪽 cross-model voice가 합의한 surface만 cut. Devil's
  Advocate가 명시적으로 defend한 항목은 손대지 않음 (ce-lfg /
  sp-using-superpowers / deep-plan + lite-plan / classification_reason /
  v010_2_paraphrase_closure / v010_3_residual_closure / NOTICE 본문 /
  docs/plans 본문 / check_vendor_drift.py — see
  `.athanor/sessions/2026-05-20-002/discuss.md` §Codex DO-NOT-CUT).
- **D2.** CHANGELOG voice = "scope-clarification" framing — "athanor
  stands alone, so CE-plugin lifecycle tooling belongs to CE." Positive
  commitment only. Forbidden phrase 회피 (단 v0.11.2 cut 대상은 v0.11.0
  / v0.11.1 forbidden list에 안 들어가서 자유도 비교적 높음).
- **D3.** Test 회귀 처리는 inversion 패턴 — v0.7.7~v0.10.3에서 deprecation
  라벨을 pin 하던 doc_string_honesty 테스트 2건을 "block must NOT exist"
  로 뒤집어 closure 자체를 lock. v0.10.3 §D6 pattern 답습.
- **D4.** Drift script 변경 없음 — script가 `skills/ce-*/`를 동적으로
  walk 하므로 cut 후 자연스럽게 33개만 iterate. 별도 maintained
  allow-missing list 불필요 (Devil's Advocate가 우려한 invariant
  redefinition은 v0.13.0 architectural cut으로 deferred).

## Risk + Mitigation

- **R1 — Vendored skill removed but still referenced in docs.** Historical
  references in `docs/plans/2026-05-19-003-*` and `docs/STATE.md` previous-
  phase sections describe the v0.10.0 set including the 4 cut skills.
  Per Devil's Advocate defense (docs/plans + STATE = release narrative
  evidence), these are NOT updated. Current-phase / active-surface docs
  are updated. Mitigation: explicit note in NOTICE.md + CHANGELOG that
  historical docs are intentionally preserved.
- **R2 — Honesty arc breach via CHANGELOG voice.** "removed" / "cut" /
  "purge" can read as supersession framing if mis-worded. Mitigation:
  use "scope-clarification" + "stands alone" positive commitment per D2.
- **R3 — Test inversion silently passes for the wrong reason.** If the
  v0.11.2 cut accidentally leaves a stale `models` key elsewhere
  (e.g., a different config file), the inverted test wouldn't catch
  it. Mitigation: pytest covers both files; grep before commit confirms
  zero "\"models\"" hits in production config.
