# feat: v0.11.0 — /athanor:lfg wrapper skill

## Summary

Add a new `/athanor:lfg` skill that wraps the LFG end-to-end pipeline in
athanor-native commands at the identity-bearing steps (plan + work +
review). Vendored `/athanor:ce-lfg` (from compound-engineering 3.8.3) is
preserved unchanged. After v0.11.0, athanor stands alone — a user with
only athanor installed (no `compound-engineering` plugin) can run the
full pipeline via `/athanor:lfg`.

Closes the v0.10.0 absorption arc's standalone narrative. v0.11.0 ships
as a single PR, single release.

---

## Problem Frame

(See origin requirements §Problem Frame.) In short: v0.10.0 vendored 50
skills but LFG still routes through `/compound-engineering:lfg` in
practice. v0.11.0 adds the athanor-native LFG so the pipeline is
end-to-end invokable through athanor commands.

## Key Decisions

- **D1**: `/athanor:lfg` is a **wrapper skill**, not an alias. The skill
  body explicitly chains athanor commands at identity-bearing steps —
  matching origin §D3 ("option 3 attachment probe").
- **D2**: Identity-bearing steps that invoke athanor-native:
  - Step 1: `/athanor:plan` (cross-model adversarial — Planner A
    Claude + Planner B Codex + Critic when codex available; fallback
    matrix in `skills/plan/SKILL.md`).
  - Step 2: `/athanor:work` (Splitter `execution_note` classification +
    conjunction-of-three Phase 3 gate per v0.8.0 Spec-then-TDD).
  - Step 3: `/athanor:review` (parallel 6-lens multi-aspect review per
    `athanor.json` `review.lenses` default).
- **D3**: Non-identity-bearing steps reuse the **shape** of vendored
  ce-lfg's steps verbatim (commit-push-pr, ci-watch). They do NOT call
  vendored `/athanor:ce-commit-push-pr` etc. as a single skill —
  instead the wrapper's prose itself contains the step instructions
  (mirroring vendored ce-lfg's flow but in the athanor-native skill
  file). This keeps the wrapper self-contained.
- **D4**: Wrapper does NOT replace the dispatch invocation of vendored
  `/athanor:ce-lfg`. Both skills coexist. Users who explicitly want
  CE's single-agent flow invoke `/athanor:ce-lfg` directly; default
  muscle-memory `/athanor:lfg` gets athanor-first.
- **D5**: Voice — no "CE deprecated" / "athanor supersedes" / etc.
  phrasing anywhere in v0.11.0 release prose. Origin §R4 carried verbatim.
  Voice regression test extended in M2.
- **D6**: Skill description trigger keywords. The skill description
  (YAML frontmatter `description:`) advertises invocation triggers in
  English + Korean — "lfg", "전체 파이프라인 진행", "ship this",
  "release this end to end", etc. — without overlapping the
  `/athanor:ce-lfg` trigger phrase set.

## Implementation Units

### U1. New `skills/lfg/SKILL.md` (`/athanor:lfg` wrapper)

**Goal:** Create the depth-1 SKILL.md that defines the 8-step athanor-
native LFG pipeline.

**Requirements:** R1, R2, R3 (origin); D1, D2, D3.

**Dependencies:** none (greenfield file).

**Files:**
- Create: `skills/lfg/SKILL.md`.

**Approach:**

Frontmatter:
```yaml
---
name: lfg
description: >
  Run the full autonomous engineering pipeline end-to-end through
  athanor-native commands at identity-bearing steps (cross-model
  planner / Spec-then-TDD work / parallel multi-lens review), then
  commit + push + PR + CI watch.
  '진행해', '전체 파이프라인', '배포해', '커밋 푸시 PR', 'ship this',
  'release this', 'lfg' 등.
user-invocable: true
allowed-tools: Bash, Read, Skill
---
```

Body sections:
- §Identity — Thin Leader reaffirmation; reference CLAUDE.md §"Vendored
  Surface" identity commitment #1.
- §When to invoke / when NOT to invoke (CE-lfg is the explicit
  alternative for CE single-agent flow).
- §Pipeline (8 steps):
  - Step 1 — Invoke `/athanor:plan` (cross-model adversarial). Gate:
    plan file exists in `docs/plans/`.
  - Step 2 — Invoke `/athanor:work` (Spec-then-TDD discipline). Gate:
    implementation files modified beyond the plan.
  - Step 3 — Invoke `/athanor:review` (parallel multi-lens). Gate:
    review surfaces no merge-blocker findings; otherwise iterate up to
    3 fix rounds. (Matches vendored ce-lfg's M-fix-iteration pattern
    but using athanor reviewer.)
  - Step 4 — Persist review autofixes (if any files changed during
    step 3, commit + push them; verbatim shape from vendored ce-lfg).
  - Step 5 — Autonomous residual handoff (verbatim shape from vendored
    ce-lfg — same `gh pr edit` / fallback file pattern).
  - Step 6 — `ce-test-browser mode:pipeline` (vendored CE skill invoked
    by name; v0.11.0 doesn't replicate browser test logic in athanor).
  - Step 7 — Commit + push + PR. Verbatim shape from vendored ce-lfg.
  - Step 8 — CI watch + autofix loop (verbatim shape from vendored
    ce-lfg — 3 fix iterations cap).
  - Step 9 — Output `<promise>DONE</promise>` when complete.
- §Difference from `/athanor:ce-lfg` — short prose pinning that:
  - athanor:lfg's step 1+2+3 invoke `/athanor:plan` / `/athanor:work` /
    `/athanor:review` (athanor identity).
  - ce-lfg's step 1+2+3 invoke ce-plan / ce-work / ce-code-review (CE
    single-agent flow).
  - Both coexist; user chooses by namespace.

**Patterns to follow:** vendored `skills/ce-lfg/SKILL.md` 9-step shape;
`skills/plan/SKILL.md` § Identity prose voice; `skills/work/SKILL.md`
§ Identity v0.10.0 vendored-surface note style.

**Test scenarios:** see U3 below.

**Verification:** `tests/test_regression_v011_athanor_lfg_wrapper.py`
asserts skill structure + content invariants.

**Execution note:** test-first per athanor Spec-then-TDD discipline.
Write the regression test first, observe RED on missing file, then
write SKILL.md.
