# Athanor v0.12.0 Migration Guide

athanor v0.12.0 atomically removes 45 vendored skills + 47 sub-agents that
were absorbed in v0.10.0 under the `/athanor:ce-*` and `/athanor:sp-*`
namespaces. **v0.10.0 plan-of-record misread the user's
concept-absorption intent as wholesale plugin vendoring;** v0.12.0 is the
scope correction. The athanor identity invariants (Thin Leader,
cross-model adversarial planning, Spec-then-TDD discipline, Stop hook
runtime gate) survive the cutover intact.

Full retrospective:
[`docs/archive/v010-v011-vendoring-scope-correction.md`](archive/v010-v011-vendoring-scope-correction.md).

  git-history discovery dispatch target (D12).

## What survives intact across the pivot

The companion-fix arc that hardened the Stop hook from v0.11.3 onward is
preserved by D10/D11:

- Stop hook runtime gate (`scripts/hooks/stop_verify_claims.py`) —
  companion-fix arc 5 layers (v0.11.3 input parser + v0.11.4 plugin-root
  path + v0.11.5 CLAUDE.md doc drift + v0.11.6 sentinel body-hash binding
  + v0.11.7 scanner extension + Residual reclassification + B1 mutation
  detection + v0.11.8 deprecation carve-out).
- All v0.11.3 → v0.11.7 companion-fix arc regression tests + v0.11.8
  deprecation preamble tests.
- Athanor identity invariants: Thin Leader / cross-model adversarial
  planning / Spec-then-TDD discipline / Stop hook gate.
- 10 user-invocable athanor-native skills.
- v0.10.2 vendor-aware whitelist (18 idioms + paraphrase regex layer +
  Cyrillic / Greek / Armenian homoglyph fold) — D11 preserves the
  detection layers with rationale re-framed to general defensive
  coverage (those idioms apply broadly to material-claim phrasing, not
  vendored-prose-specific).

## If you depend on a removed CE or SP skill

Install the upstream plugin directly (both are MIT-licensed):

- **compound-engineering**: https://github.com/EveryInc/compound-engineering-plugin
- **superpowers**: https://github.com/obra/superpowers

athanor v0.12.0 stands alone as a Thin Leader orchestrator. The companion
plugins coexist cleanly because the athanor namespace no longer overlaps
with the upstream namespaces (except for the 1 KEEP `/athanor:ce-test-browser`
slot).
